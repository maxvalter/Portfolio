Background

And-The-Revolution is a bicycle shop in central Stockholm where customers configure custom builds when making a purchase. The site runs on WordPress with Tailpress and a custom Bikebuilder plugin. Both the Bikebuilder and the site as a whole had long-standing bugs and usability problems.

Solution

I reviewed the custom PHP code, admin settings, and Tailpress theme to resolve a range of issues:

  • Repaired the Bikebuilder plugin so displayed images and price calculations behave correctly.
  • Fixed the shopping cart so it stores and displays the correct items.
  • Unified typography and styling across the site according to the design system.
  • Fixed layout bugs on smaller screens.
