Research + Product Design | Agentic AI | LangChain | UX

An agentic chatbot for the Flowpass platform, built with LangGraph and custom tools that answer questions using each user's environment data.

Background

A research-driven thesis project exploring how agentic AI can improve first-use confidence and clarity in complex service experiences.

Solution

An agentic chatbot for the Flowpass platform, built on LangGraph with custom tools that call the backend API and answer questions about a user's platform environment. Accuracy and performance were iteratively improved using LangFuse agent tracing.
